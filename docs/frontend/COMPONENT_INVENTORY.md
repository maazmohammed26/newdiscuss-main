# Discuss UI Component Inventory

## Primitives Layer
- `AppButton`: Primary, secondary, ghost, danger variants. Immediate pointer-down scaling.
- `IconButton`: Normalized 44px touch target, 18-24px optical icon size.
- `UserAvatar`: Fallback initials with deterministic tone, verified badge overlay support.
- `TextField` & `SearchField`: Clean borders, subtle focus ring, clear action.
- `Switch`: iOS-grade toggle switch with spring physics.
- `BottomSheet`: Gesture-dismissible mobile sheet with safe area inset.
- `Dialog`: Accessible modal dialog for desktop screens.
- `Badge`: Status and counter indicators without emojis.
- `Skeleton`: Shimmering placeholder blocks matching actual typographic line-heights.
- `EmptyState`: Purposeful empty state illustration-free component with icon and actionable CTA.
- `ErrorState`: Friendly error boundary with retry action.
