# Discuss Screen Migration Plan & Status

## Migration Sequence & Milestones
1. **Design System Tokens & Typography**: Complete tokens in CSS, normalize typography scale.
2. **Interaction Feedback & Sound Service**: Zero-dependency Web Audio service with settings toggle.
3. **App Shell & Floating Navbar**: Mobile minimal bottom navigation, desktop persistent rail.
4. **Feed & Post Hierarchy**: Instagram-level post cards with clean typography, actions, zero emojis.
5. **Messaging & Conversation**: WhatsApp-level clarity, instant optimistic bubbles, status indicators (sending/sent/failed).
6. **Groups & Profile**: Clean grouped sections, native settings switches.
7. **Stories, Blink, DevRadar**: Camera-first Blink, native-feeling story rings, interactive radar map.
8. **Auth & Landing**: Streamlined auth flow, brand-aligned landing view.
